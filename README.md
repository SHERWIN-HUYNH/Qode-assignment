# Qode Photo Feed

Qode is a simple photo-sharing app built with Next.js. Users can upload images, add a caption, browse a paginated feed, open individual photo pages, and post comments.

## Stack

- Next.js 16 + React 19
- Prisma with Postgres/Neon
- Cloudinary for image storage
- Ant Design + Tailwind CSS for UI

## Features

- Upload JPG and PNG images up to 10MB
- Save image assets in Cloudinary
- Store image records and comments with Prisma
- Browse recent uploads in a paginated gallery
- View a photo detail page with its comments
